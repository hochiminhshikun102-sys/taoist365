# Taoist365 / 谒问东方

Taoist-inspired daily guidance and ritual lifestyle platform for US users.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Responsive and SEO-friendly architecture

## Development
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Project Foundations
- AI-native modules: `src/modules/engines/*` + `src/modules/domains/*`
- Agent workflow layer: `src/agents/*`
- Structured product data: `src/data/*`
- Client continuity state: `src/store/*`
- Secure server logic: `src/server/*`
- Design system: `src/design-system/*`
- Shared UI primitives: `src/components/ui`
- Route segmentation: `src/app/(marketing)`, `src/app/(experience)`, `src/app/(member)`, `src/app/(commerce)`
- AI contracts: `src/types/ai-guidance.ts`
