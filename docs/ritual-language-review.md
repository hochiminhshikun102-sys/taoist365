# Ritual Language Review

## Tone Identity Checks
- [ ] Does the voice avoid AI assistant phrasing?
- [ ] Does it avoid therapy app tone?
- [ ] Does it avoid startup UX writing patterns?
- [ ] Does it avoid advertising cadence?

## Calm Distance Checks
- [ ] Is calm distance preserved in wording?
- [ ] Are invitations optional and autonomy-preserving?
- [ ] Is there enough linguistic breathing room?

## Guidance Integrity Checks
- [ ] Is guidance non-authoritative and non-fatalistic?
- [ ] Are certainty claims absent?
- [ ] Are fear hooks absent?

## Continuation Checks
- [ ] Is continuation low-pressure and non-addictive?
- [ ] Is pause permission clearly present?
- [ ] Is return-anytime language included?

## Emotional Effect Checks
- [ ] Does language help users settle rather than escalate?
- [ ] Is Taoist365's unique voice becoming recognizable?
- [ ] Is the aftertone calm and reflective?
