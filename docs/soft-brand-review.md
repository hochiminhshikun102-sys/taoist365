# Soft Brand Review

## Memory Over Visual Checks
- [ ] Do users remember the feeling more than visual symbols?
- [ ] Is emotional aftertaste present without pressure?
- [ ] Is recall driven by rhythm and silence rather than graphics?

## Over-Branding Checks
- [ ] Is logo presence restrained?
- [ ] Is there any slogan-like repetition pressure?
- [ ] Is campaign aesthetic absent?

## Spatial Personality Checks
- [ ] Is there a stable Taoist365 spatial personality across pages?
- [ ] Do spacing, reveal, and motion feel from one world?
- [ ] Is calm distance preserved?

## Marketing Drift Checks
- [ ] Is there conversion-led identity drift?
- [ ] Is there startup brand-system mimicry?
- [ ] Is attention-first visual behavior absent?

## Long-Memory Checks
- [ ] Does the experience leave a gentle lingering sense?
- [ ] Is familiarity building slowly and quietly?
- [ ] Is pause still supported at every key transition?
