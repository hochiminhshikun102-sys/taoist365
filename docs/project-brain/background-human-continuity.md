# Background human continuity

## Why mail reads as shelf traces, not “contact product”

Correspondence that ages in place feels like **paper on a shelf**: uneven replies, long silences, no pipeline language. That is continuity without CRM framing—no resolution UI, no “finish this thread” energy.

## What ships in code

- `src/data/mail-background-continuity/*` — passive thread, shelf presence, no-resolution runtime.
- UI: `MailTemporalPresence`, `MailContinuityStrip` use **`invisibleInfrastructureStructuralThinning`** (`mailRetireDenseProcessBlock`, `combinedProseBias`) to retire dense process copy while keeping humane residue.

## Forbidden

Session continuity features, push, service-default nagging.
