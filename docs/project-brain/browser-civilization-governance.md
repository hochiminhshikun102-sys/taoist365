## Drift Prevention

The executable check is `npm run guardrail:governance`. It must stay passing before production changes land.

It protects against app drift, dashboard drift, marketplace drift, assistant drift, AI-startup tone, spiritual-platform tone, atmosphere over-design, luxury calmness, emotional dependency, feed behavior, retention hooks, and production asset recontamination.

`npm run guardrail:infrastructure` is the same executable layer named for long-term handoff. It also protects package-script continuity, public archive isolation, required production assets, production brand references, and Browser Air token anchors.

## Browser Air Consistency

Browser air is governed through stable globals, low-motion behavior, ordinary spacing, muted contrast, and long-open softness. A page should feel like the same quiet browser room, not a separate premium surface.

Keep:
- ordinary browser language
- low visual pressure
- stable typography scale
- reduced-motion support
- soft contrast
- sparse interaction

Avoid:
- cinematic calmness
- luxury minimalism
- app-shell density
- feature panels
- attention competition
- designed warmth that announces itself
