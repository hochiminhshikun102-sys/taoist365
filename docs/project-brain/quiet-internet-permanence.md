# Quiet Internet Permanence

## Role

Plain, non-theatrical language for **long-lived URL** behavior: unchanged pages, stable URLs, long-open tabs, hostname defaultness, background-site feel. Explicitly **not** nostalgia aesthetics or webcore.

- `worldQuietPermanence.quietInternet`
