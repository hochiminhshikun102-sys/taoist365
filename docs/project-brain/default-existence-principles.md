# 默认存在原则（Default Existence）

## 五条「为什么」

1. **成熟站点会越来越少表达**——不是懒，而是默认；话少是均衡，不是故障。  
2. **世界从 interaction 退回存在**——网址不必每次「发生」；切回 tab 就够。  
3. **Guidance 接近「天气 + 房间 + 离开」**——像亮着的角落，不像助手会话。  
4. **Objects 从「产品」退成房间结构**——坐标与物在，推销句退休。  
5. **终极目标不是活跃，是长期默认存在**——安静、稳定、无需自证。
