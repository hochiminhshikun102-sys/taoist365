# Self-restraint philosophy

## Expansion vs restraint

Healthy long-term behavior is **negative feedback**: new copy surfaces owe silence; prose stacks trigger collapse bias; strips retire before they multiply.

## Code

- `src/data/world-self-restraint/*` — restraint, anti-expansion, thinning pressure language.
- `extreme-governance-thinning-pass.ts` implements downward pressure on prose density without meta footers (“we are shrinking”).
