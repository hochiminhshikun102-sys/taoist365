# Silence Governance

## What “the world knows when to shut up” means

1. **Silence is scheduled** — by `dayKey`, age state, page energy, and regulation loads — not by guessing user mood.
2. **Silence is legible** — when a block is missing, another surface still reads as a **URL** (domain line, same-day climate, shareable anchor, navigation), not as an error shell.
3. **Silence is mutual** — runtimes **suppress** each other (e.g. strong materialization → fewer human trace paragraphs) so everything does not speak at once.

## Formal silence governance bundle

`src/data/silence-governance-system/*` adds charter-level lines for absence budgets, residue retirement, and default-quiet stance. **`silence-priority-system`** (`silence-priority.md`) states silence-first priority; numeric thinning ends in **`worldAiNativeInfrastructure.invisibleInfrastructureStructuralThinning`**. Structural gates in this table still take precedence.

## Allowed absence

- Entire **noticing** stack in Guidance when collapse + fragmentation demand it — **weather + label + closure** must remain.
- **Echo blocks** on Daily when overflow or daily understatement — core climate + shareable remain.
- **Object cards** not in `regulatedForegroundIds` — list shortens; page copy and anchors remain.
- **Mail** explanatory paragraphs under `mailUnderstatement` — shelf time + rhythm remain.

## Forbidden patterns

- Feed cadence, streaks, “continue exploring,” personalization hooks.
- Blank screens with no hierarchy, no title, no back path — **not** acceptable silence.

See `absence-policy.md` for copy-level bans and `anti-performance.md` for tone bans.
