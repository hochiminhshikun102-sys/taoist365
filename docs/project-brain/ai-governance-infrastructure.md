# AI governance infrastructure（AI 治理基础设施）

## 快速对齐

- **治理（governance）** = 边界先于表面：任何通道（Guidance / Mail / Objects / 未来 commerce）都不能在长期尺度上**突破**已有的 world governance 语言与数值 caps。
- **`ai-governance-infrastructure`** 承载「强制执行语气」的文案原子：**anti-drift（反漂移）**、**anti-productization（反产品化）**、**anti-companion（反陪伴人格）** 等—全部是静态 bundle，不是策略引擎 UI。

## 本文件定义什么

为何「未来真正重要的不是裸 AI 能力，而是 **AI governance（AI 治理）**」：能力无边界时会通向 companion / feed / growth loop；治理决定能否十年不坏口味。

## 核心原则

1. **压制而非解释**：用 thinning（变薄）与 restraint（克制）落实治理，不对访客说教「被治理了」。
2. **World Governance 至上**：regulation（调控）与 governance bundles 的硬逻辑优先；基础设施层只追加长期默认压力。
3. **红线**：无 control panel（控制面板）、无 enforcement 可视化、无人格化「守卫」。

## 代码锚点

- `src/data/ai-governance-infrastructure/*` — `resolveAiGovernanceInfrastructureBundle()`
