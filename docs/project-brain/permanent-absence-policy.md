# Permanent Absence Policy

## What never returns as foreground copy

- The site explaining its own runtime stack to the visitor.
- “Runtime talk,” worldbuilding meta-narration, AI-aware prose that performs intelligence.

## Where enforced

- `world-freeze-system/permanent-absence.ts` and policy line on the freeze bundle.
- `anti-system-self-awareness` and structural silence still handle day-level suppression; permanent absence is the **moral** floor, not a separate gimmick.

## Review

- When adding new copy modules, scan for second-person instruction that sounds like a system winking at itself; redirect to ordinary room or mail language.
