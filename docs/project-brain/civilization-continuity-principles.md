# Civilization continuity principles（文明连续性原则）

## 为何不是用户记忆

- **User memory profile（用户记忆画像）** 会不可避免导向 personalization（个性化）、推荐与 engagement loop（参与度闭环），与本项目红线冲突。
- **World continuity（世界连续性）** 使用匿名、同日、同气候键的共享沉积—像房间落灰，而不是像账号履历。

## 原则清单

1. **Structural before narrative**：结构缺席与变薄先于故事化修补。
2. **Same place, quieter**：时间推进默认走向更安静，而非更嘈杂的「成长叙事」。
3. **Deterministic residue**：残余应是可复现的函数输出，不是随机「懂你」。

## 与 AI governance 的关系

- continuity bundles **服从** governance infra：`runtime` 可以自治协商 foreground，但不得突破治理边界（见 `ai-governance-infrastructure.md`）。
