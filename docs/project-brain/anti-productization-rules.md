# Anti-productization rules

## Hard bans (governance phase)

- Accounts, profiles, dashboards, recommendation engines, feeds, personalization, push, chat-shell UI, memory, continue-session, streaks, achievements, gamification, companion loops, content growth mills, infinite rotation.

## Soft bans (tone / aesthetics)

- Lifestyle branding, indie-web cosplay, fake retro internet, slow-living aesthetic performance, mystic service packaging.

## Meta bans on the page

- “AI civilization,” explicit runtime self-narration, “this site is aging,” “this is an experiment,” worldview theater.

## Enforcement

Data bundles in `world-governance-engine/` spell posture; the thinning stack ending in **`invisibleInfrastructureStructuralThinning`** reduces operational temptation without adding explanatory UI about governance.
