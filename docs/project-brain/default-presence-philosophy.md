# Default Presence Philosophy

## Five “why” notes (project brain)

1. **World quieter ≠ bug** — High `proseCollapseBias` reduces overlap and explanation pressure so the site reads **default**, not broken.
2. **Page absence = maturity** — Structural absence and thinning pass remove blocks **deterministically**; empty space is layout memory, not loading failure.
3. **No meta runtime talk** — Long-lived URLs do not explain their stack to visitors; charter lines live in data for authors, not as self-aware prose.
4. **Objects in background > endless spotlight** — Infrastructure posture beats catalog theater; `object-background-continuity` encodes that direction.
5. **Guidance → weather + one line + exit** — Endgame is a **lit room**, not a companion; `guidance-quiet-collapse` + dissolution move session UI toward that without removing the route.

## Technical guardrails

Pacific-day keys, static export, no backend memory, no personalization—unchanged from global brain rules.
