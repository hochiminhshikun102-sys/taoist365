# Passive Worlds

## Definition

A **passive world** day is when **fatigue + rest + channel retirement** keep most runtimes in background—pages stay legible with **fewer blocks**, not empty error states.

## Signals

- `runtimeRetirement.worldRest.restDay`
- `runtimeRetirement.worldFatigue.fatigueLevel` in `resting` / `almostAbsent`
- `guidanceRetirement.ultraMinimalRoom` for Pause session

## Layout rule

Absence must leave **titles, weather, and a path home**—never a blank shell. See `GuidanceSessionClient` ultra-minimal branch and `absence-policy.md`.
