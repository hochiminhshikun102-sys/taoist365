# Runtime anti-reactivation protocol（运行时反再激活）

**Phase:** Content reserve purge — reserves are a drift vector.

## Forbidden patterns

- Re-importing **removed echo fields** on `LivingDailySlice` (`arrivalEcho`, `longTermEcho`, `humanRoomEcho`, `timeSedimentEcho`) without an explicit product decision and dated `decisions-log.md` entry.
- Growing **`livingDailySlices`** back into multi-paragraph literary pools.
- Restoring **`LivingDailyBand`** `useWorldRuntime` prose stacks removed in Data Silence era.
- Adding **fallback “deeper mode”** copy paths (sacred / spiritual / reflective coaching) to marketing or ritual shells.

## Allowed

- **Utility strings**: mail paths, legal/safety one-liners, inventory facts.
- **Short status lines** from inertia/layout tokens already flattened.

## Before enabling new routes or AI features

1. Grep `src/data/**` for `melancholy|sacred|existential|emotional weather|inner stillness` (extend list per `terminology-governance.md`).
2. Confirm no new **atmosphere coordinator** pipes user-visible prose without caps.
3. Append **decisions-log.md** if reactivating any deprecated reserve.

## Deprecated markers

- `living-content/daily-slices.ts`: **echo reserves removed** — do not restore without protocol above.
- `home-linger.ts`: **paragraph reserve** reduced to domain facts — do not expand into therapy-adjacent prose.
