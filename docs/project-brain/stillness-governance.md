# Stillness Governance

## Purpose

As the world “ages” in the deterministic model, **pressure to change** should meet counterweights: change pressure scalar, prose density governor, anti-expansion, runtime cooling, stability preservation, quiet world protection, overgrowth audit. Data: `src/data/world-stillness-governor/` → `worldMaturity.stillnessGovernor`.

## Inputs

- `structuralSilence`, `world-aging-runtime`, `world-regulation-engine`, `runtime-retirement-system` (fatigue, overflow flags) feed `resolveWorldStillnessGovernorBundle`.

## Use

- `proseDensityGovernor` (0–1) is available for future thinning of dense stacks; today Home strip reads a single anti-expansion line alongside freeze and aging copy.
