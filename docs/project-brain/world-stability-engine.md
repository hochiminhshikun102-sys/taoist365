# World Stability Engine

## Distinction from `world-stability-governance`

- **`world-stability-governance`** — friction, change resistance, budgets (first stability scalar).
- **`world-stability-engine`** — **lock / freeze / permanence** language: long-form freeze, ambient permanence, static pressure, unchanged structure, layout memory.

## Bundle

`resolveWorldStabilityEngineBundle(structuralSilence, worldRegulation, worldStability)` → `WorldStabilityEngineBundle` including **`engineStabilityScalar`** fed into **runtime retirement pressure** (stronger engine → faster channel drift toward background).

## Intent

Communicate **old-site stability**: home structure, Daily cadence, and Mail prose **allowed** to stay unchanged for long spans—**not** “we shipped an update.”

## Non-goals

- Changelog theater, feature announcements, freshness marketing.
