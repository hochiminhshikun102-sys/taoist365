# Default presence infrastructure（默认在场基础设施）

## 快速对齐

- **Default presence（默认在场）**：页面的大多数日子应当「像没打扰你」；基础设施层通过 **`invisibleInfrastructureStructuralThinning`** 把 **combinedProseBias（综合文案偏置）** 往高安静区间推，而不引入新的 interaction（交互）壳层。
- 本文件连接 **default existence layer（默认存在层）** 与 **AI-native infra layer**：前者提供 base `structuralThinning`，后者提供最终 UI-effective pass。

## 本文件定义什么

回答：Taoist365 的目标不是 **增长（growth）**，而是 **长期存在（long-term persistence）**—存在感的默认状态应接近基础设施，而不是 campaign 式运营。

## 设计要点

1. **单一 UI thinning 出口**：组件只读 `worldAiNativeInfrastructure.invisibleInfrastructureStructuralThinning`，避免多层「谁说了算」分叉。
2. **失败形状**：安静不应像 bug；靠排版节律与确定性缺席语义支撑（见 `structuralSilence` 文档）。
3. **红线**：无 personalization、无 memory profile。

- 链：`structuralThinning` → … → `invisibleInfrastructureStructuralThinning`（见 `runtime-systems.md` §21–§26）
- 调参入口：`extreme-invisible-infrastructure-thinning-pass.ts`（优先）
