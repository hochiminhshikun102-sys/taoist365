# 世界安静均衡（World Quiet Equilibrium）

## 意图

世界 **自稳**：压 prose、压 route、压 section、压 echo、压自我说明感；安静是均衡，不是挂掉。

## 代码

- `src/data/world-quiet-equilibrium/*` → `worldDefaultExistence.quietEquilibrium`  
- `equilibriumPressure` 参与 `structuralThinning.combinedProseBias` 计算。

## 与 `world-stillness-equilibrium.md` 区分

`world-stillness-equilibrium.md` 文档对应 **post-product** 阶段的 stillness stabilization；本文件对应 **默认存在** 阶段的 quiet equilibrium **包**。
