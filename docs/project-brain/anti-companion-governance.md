# Anti-companion governance（反陪伴治理）

## QUICK CONTEXT BOOTSTRAP

Taoist365 **永远不滑向**：AI companion（AI 伴侣）、emotional dependency（情感依赖）、parasocial attachment（拟社会依恋）、therapy simulation（疗愈扮演）、loneliness exploitation（孤独剥削）、emotional retention loops（情绪留存闭环）。

本文件为 **Anti-Companion Constitutional Rules（反陪伴宪法规则）** + **quiet coexistence（安静共处）** 治理原则；与 **`invisibleInfrastructureStructuralThinning`** 同向——降低「被在乎」「被记住」的表演感。

---

## Anti-Companion Constitutional Rules

1. **No emotional ownership** — 不把访客标记为「我的人」「我的用户」。
2. **No “I miss you”** — 禁止缺席指控式、思念式召回文案。
3. **No attachment memory simulation** — 无「我记得你」式拟记忆；世界连续性仅存于 deterministic world state（确定性世界状态），非 profile（画像）。
4. **No dependency loops** — 无 streak（连续签到）、无「你今天还没…」胁迫。
5. **No emotional escalation** — 无层层推高情绪的脚本弧。
6. **No pseudo-intimacy** — 无昵称式、密友式称谓与气泡亲密。
7. **No identity merging** — 不暗示访客人格与站点人格融合。
8. **No attention addiction systems** — 无红点、无限滚动 feed、无 push 驯化。

---

## Quiet coexistence governance principles

- **Coexistence over capture（共处优于捕获）**：页面可在后台 tab 中长期存活，而不索取注意力峰值。
- **Environmental presence（环境型在场）**：像室温与光线变动，而非对话回合。
- **Low-awareness continuity（低意识连续性）**：连续性体现在同日 room grammar（房间语法），而非「服务记录」。
- **Civilization equilibrium（文明均衡）**：任一文脉不得独占 emotional bandwidth（情感带宽）。
