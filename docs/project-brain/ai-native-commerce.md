# AI-native commerce（AI 原生商业 / low-signal commerce）

## 快速对齐

- **Low-signal commerce（低信号商业）**：商业行为允许存在，但必须贴近 **noise floor（噪声底）**：无转化中心叙事、无紧迫感默认、无推荐引擎式推销语言。
- `ai-native-commerce` 目前是 **infra vocabulary（基础设施词汇）** 层，为未来 commerce 通道预埋 restraint（克制），不是开店 UI。

## 本文件定义什么

记录红线：**commerce（商业）** 必须永远低 signal；与 governance infra 一起压制 **conversion theater（转化戏剧）**。

## 核心原则

1. **Fulfillment background（履约后台化）**：履约与流程描写尽量退到 mail/object 类的 background sediment（背景沉积）语气。
2. **Anti-conversion pressure（反转化压力）**：用 bundle 语言与变薄链抑制「漏斗感」。
3. **红线**：无 recommendation engine（推荐引擎）、无 gamification（游戏化）、无 dashboard。
