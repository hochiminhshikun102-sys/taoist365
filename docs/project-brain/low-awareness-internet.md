# Low-awareness internet（低意识互联网）

## 快速对齐

- **Low awareness（低意识）**：站点尽量不唤起「正在被服务 / 正在被引导」的注意；像 **browser environment（浏览器环境）** 的一部分，而非努力表现的 brand（品牌）主页。
- `low-awareness-internet` bundle 提供默认、克制、tab-equilibrium（标签页均衡）等语气支柱。

## 本文件定义什么

支撑 Phase H：**更少 hierarchy（层级）**、更少 strips（横条模块感）、更强「默认网址」气质—通过 **`invisibleInfrastructureStructuralThinning`** 落在组件里，而不是加 home 教程。

## 核心原则

1. **Non-performative presence（非表演式在场）**：不把「我在」当成卖点。
2. **Quiet URL defaultness（安静 URL 默认）**：hostname（主机名）与长标签行为保持机械、低隐喻（由浏览器现实层具体执行，本包提供 infra 侧对齐语言）。
3. **红线**：禁止「AI 正在工作」、禁止 growth optimization（增长优化）话术。
