# World aging without upgrading（世界老化而非升级）

## Distinction

| World aging（世界老化） | Product upgrading（产品升级） |
|-------------------------|-------------------------------|
| 同龄键下沉静、文案变薄 | changelog、banner、紧迫感 |
| sediment（沉积） | feature list |
| room gravity | onboarding |

## Code alignment

`world-aging-runtime`、`real-internet-aging`、`materialization` touch sediment lines — **not** release notes UX。

## Visitor feeling

「这个地方旧得很安心」而非「我得更新认知」。
