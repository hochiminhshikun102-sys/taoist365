# Silence preservation（沉默保全）

## Goal

冻结阶段的首要产出是 **silence preserved（沉默被保留）**：空白 band、无 closure、无 route 的日子仍然「体面」，不像坏掉的 SaaS。

## Mechanisms

- Structural silence hard gates。
- Terminal thinning：`invisibleInfrastructureStructuralThinning`。

## Anti-pattern

用噪音填补沉默（教程、提示条、「我们更新了」）。
