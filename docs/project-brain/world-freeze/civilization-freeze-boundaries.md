# Civilization freeze boundaries（文明冻结边界）

## What may change post-freeze

- Thinning weights、copy tier、缺席阈值、沉积语气 — **在同一伦理边界内**调整。
- Bugfix、可达性、a11y、静态导出兼容性。

## What must not reopen

- Feed、streak、push、personalization backends、assistant shells。
- 「大版本」营销弧、changelog 剧场占据首页语气。

## Boundary test

若改动让读者感到 **「又要跟上新版本」** → 违反冻结边界。
