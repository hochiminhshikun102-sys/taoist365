# Non-expansion governance（非扩张治理）

## Definition

**Non-expansion** = 默认 **no new routes / no new product shells**；扩张只在文档与代码中被 **显式否决**，而非被 OKR 驱动。

## Relationship

姊妹文档：`../anti-expansion-governance.md`（既有章程）。本文件强调 **post-infrastructure freeze（后基础设施冻结）** 语境下的同一纪律。

## Operational rule

任何 PR 标题含「增长」「转化」「留存」→ 退回 **`equilibrium-first`** 语言重写（见 `../runtime-equilibrium/equilibrium-without-growth.md`）。
