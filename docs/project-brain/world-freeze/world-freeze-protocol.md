# World freeze protocol（世界冻结协议）

## Purpose

**World freeze（世界冻结）**：承认界面背后的「世界」已被 **`world-freeze-system`** 与治理栈塑形；本阶段拒绝 **infinite evolution（无限进化）** 叙事与「持续升级」文化。

## Principles

- **The world is formed（世界已经形成）** — 改动应是沉积与变薄，不是版本竞赛。
- **No infinite feature stacking** — 新表面默认关闭，除非通过 freeze / drift checklists。
- **World aging ≠ product iteration（世界老化 ≠ 产品迭代）** — 老化抬高 quiet bias；迭代抬高 novelty bias。
