# Project Brain

Current canonical public identity: Reverent Inquiry on taoist365.com.

## QUICK CONTEXT BOOTSTRAP

- Taoist365 is a **Taoist-inspired lifestyle guidance system**: static Next.js, **quiet ritual atmosphere**, **ritual calm**, **breathable interfaces**, and cross-page **emotional continuity** via `useWorldRuntime()`—not chat, SaaS, or social.
- Runtime stays deterministic (Pacific day key + world state), static-export safe, and non-personalized.
- **Low-signal humanity** and structural maturity are first-class; this folder outranks one-off experiments when intent conflicts.
- Priorities: update brain when behavior ships; tune silence and coherence before adding surfaces; log changes in `decisions-log.md`.
- **Terminology lock**: **`civilizationStabilizedStructuralThinning`** = intermediate / transitional / **non-final** atmosphere pass; UI **only** reads **`invisibleInfrastructureStructuralThinning`** — see `terminology-governance.md`.

## THIS DOCUMENT DEFINES

The role of `docs/project-brain/` as long-term memory: reading order, shared identity, and how the other brain files connect.

## CORE PRINCIPLES

- Preserve **quiet ritual atmosphere**: warm, grounded, **low-signal humanity**—no mystic theater, wellness hype, or feed energy.
- **Emotional continuity** across pages for a given day beats isolated spectacle peaks; **ritual calm** beats persuasion.
- When docs conflict: see **`memory-protocol.md`** for full hierarchy; default: `docs/project-brain/*` → `src/data/*runtime*` → `src/app` / `src/components` → new ideas.
