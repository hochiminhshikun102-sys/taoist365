# Real Internet Aging

## Purpose

Plain **long-URL** semantics: autocomplete memory, bookmark bar, tab return fatigue, cached familiarity, hostname aging, old page stability, quiet revisit—**ordinary** browser life, not nostalgia theater or fake retro webcore. Data: `src/data/real-internet-aging/` → `worldMaturity.realInternetAging`.

## Boundaries

- Allowed: “might have been open in a tab a long time,” “URL starts to feel familiar,” “autocomplete surfaces first.”
- Forbidden: staged nostalgia, webcore aesthetics, fake retro internet.

## Relationship to other bundles

- Complements `browser-reality-engine`, `low-refresh-internet`, `internet-sediment-maturity`, `real-internet-defaultness`; this package is **copy-only policy lines** for the stabilization phase, not a duplicate tab engine.
