# Background Object Governance

## Charter

Objects leave **catalog hero** posture: room infrastructure, repeat contact over spectacle, optional **no-prose days** (`objectNonDisplayDay`), explanation collapse at high world age.

## Code

- `src/data/object-background-continuity/*`
- `worldPostProductContinuity.objectBackground`

## UI

`RealObjectPresencePanel` and `ObjectPermanenceStrip` respect `permanencePass` and `objectBackgroundBias`.

## Why backgrounding is “higher” than spotlight

Spotlight trains a storefront reflex; long default presence trains **ordinary room gravity**—see `default-presence-philosophy.md`.
