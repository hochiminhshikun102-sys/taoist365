# Hostname Familiarity

## Definition

**Hostname familiarity** is recognition of **`taoist365.com` as a URL**—position in the bar, autocomplete, bookmarks—not admiration for “how good the site is today.”

## Data

- `browserReality.hostname` from `hostname-familiarity.ts` (uses `siteConfig.domain`)

## Copy rules

- Favor **positional / mechanical** language (autocomplete, bar, typing a few letters).
- Avoid **brand campaign** tone: no slogans, no “join millions,” no superiority.

## UI

- Guidance arrival, Mail shelf block, Objects footer (`BrowserHostnameFoot`).
