# 后交互互联网（Post-Interaction Internet）

## 意图

站点从「你来用一下」转向「**一直在那儿**」：没有 session 感、没有完成弧、没有陪伴剧本。交互退潮后，剩下的是 **默认存在** 与浏览器侧的长期习惯。

## 实现

- `worldDefaultExistence`（`src/data/world-default-existence-layer/system.ts`）聚合默认存在、被动共存、房间溶解、后交互 guidance、永久低线程 mail、安静均衡、默认网址引擎，以及 **重度** `structuralThinning`。

## 红线

无 onboarding、无 profile、无记忆、无 feed、无 push、无 gamification、无 meta 自叙——与全局 `memory-protocol` 一致。
