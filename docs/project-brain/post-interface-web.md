# Post-interface web

## Why interfaces eventually thin

Dense UI assumes frequent intent: every visit is an operation. Long-lived calm assumes the opposite: most visits are **non-events**. Thinning is not removing content for shock value; it is lowering hierarchy and chrome so structure feels like furniture.

## What ships in code

- `src/data/interface-dissolution-engine/*` — language for thinning borders, headings, and “product stacks.”
- **Thinning stack:** `ambientStructuralThinning` → `governedStructuralThinning` → **`ecologyCalibratedStructuralThinning`** (`extreme-ecology-calibration-thinning-pass.ts`) → **`civilizationStabilizedStructuralThinning`** (`extreme-civilization-stabilization-thinning-pass.ts`, **intermediate / non-final**) → **`invisibleInfrastructureStructuralThinning`** (`extreme-invisible-infrastructure-thinning-pass.ts`, **UI-final**); **UI-effective only** = **`worldAiNativeInfrastructure.invisibleInfrastructureStructuralThinning`** (`terminology-governance.md`).

## Readability

Fewer emphases and labels, not smaller type to illegibility. When Daily or Guidance feels too empty, tune thresholds in `structural-thinning-pass.ts` and `extreme-structural-thinning-pass.ts`, not by re-adding feed language.
