# Quiet environment governance

## Governance without meta-runtime

Quiet governance here means: **policies live in data modules and passes**, not in footer copy that explains the policies. Users should not read “the system regulates itself” on the page.

## Where rules live

- `runtime-retirement-system`, `world-regulation-engine`, `structural-silence-engine` — hard gates and caps.
- `structural-thinning-pass.ts` + **`extreme-structural-thinning-pass.ts`** — graduated UI quieting.
- `worldAmbientInternet` — ambient bundles + `ambientStructuralThinning`（中间层）。
- `worldGovernance` — **`governedStructuralThinning`** (middle stack).
- `worldEcologyCalibration` — **`ecologyCalibratedStructuralThinning`** (intermediate stack).
- `worldCivilizationStabilization` — **`civilizationStabilizedStructuralThinning`** (**intermediate / transitional / non-final atmosphere pass** — not UI-terminal).
- `worldAiNativeInfrastructure` — **`invisibleInfrastructureStructuralThinning`** for components (final stack).

## Doc hygiene

When adding a new bundle, register it in `runtime-systems.md`, `runtime-hierarchy.md`, and `decisions-log.md`; keep README file index in sync.
