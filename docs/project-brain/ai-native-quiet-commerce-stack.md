# AI Native Quiet Commerce Stack

This file keeps the commerce continuity layer for taoist365.com. It is not an ecommerce platform plan.

## Purpose

Commerce may exist on taoist365 only as object continuity:

- ordinary objects with stable anchors;
- human mail correspondence;
- slow object placement;
- source memory when useful;
- AI-readable object semantics;
- restraint-first wording protection.

The site must not become a store, funnel, marketplace, recommendation engine, or AI sales system.

## Object Commerce Ontology

Objects are things before they are commerce.

Allowed object structure:

- stable id;
- name;
- anchor;
- plain kind;
- room placement;
- human mail path;
- source or provenance note when it clarifies the object;
- absence or availability stated without scarcity pressure.

Forbidden object structure:

- SKU-first naming;
- ranking fields;
- popularity fields;
- urgency fields;
- conversion metadata;
- recommendation categories;
- behavioral targeting.

## AI-assisted Product Presence

AI may help keep object presence consistent.

Allowed AI roles:

- compare object wording against restraint boundaries;
- keep object names, anchors, and semantics consistent;
- thin wording that starts to persuade;
- help summarize provenance plainly;
- catch ecommerce drift before it reaches the page.

Forbidden AI roles:

- sales automation;
- generated persuasion copy;
- SEO commerce copy;
- recommendation tuning;
- dynamic offers;
- autonomous merchandising.

AI helps continuity. It does not help sell.

## Quiet Placement Commerce

Commerce placement uses the same quiet placement rules as the rest of the site.

Allowed:

- a few objects on the homepage;
- object movement by human choice;
- low-frequency replacement;
- seasonal object presence without announcement;
- Windkeep-style circulation without marketplace behavior.

Forbidden:

- campaign slots;
- banners;
- featured product pressure;
- sale events;
- homepage promotion systems;
- carousel rotation for commerce.

Placement should feel like a shelf being tended.

## Human-guided Commerce Governance

Humans own:

- object selection;
- placement decisions;
- availability wording;
- source relationships;
- mail replies;
- whether something should disappear.

AI supports:

- semantic consistency;
- drift checks;
- wording repair;
- object continuity memory;
- supply notes organization.

Human judgement outranks AI optimization.

## Supply Continuity

Supply chain memory is allowed only as object continuity.

Allowed:

- source notes;
- maker or supplier memory;
- provenance when useful;
- batch variation described plainly;
- unavailable state without drama.

Forbidden:

- ERP vocabulary;
- sourcing optimization;
- scaling strategy;
- industrial complexity;
- vendor performance dashboards;
- scarcity theater.

Supply memory should help a human understand where an object came from, not make commerce feel larger.

## Semantic Commerce Infrastructure

AI-readable commerce should remain descriptive.

Allowed:

- object anchors;
- object kind;
- mail-only correspondence;
- boundaries against checkout and platform behavior;
- static semantic continuity.

Forbidden:

- keyword stuffing;
- GEO spam;
- crawler persuasion;
- product schema inflation for ranking;
- synthetic review or popularity signals.

Continuity is more important than traffic.

## Quiet Commerce Observation

Observe after object or commerce changes:

- objects still read as things, not SKUs;
- mail still reads as correspondence, not checkout;
- homepage placement does not become promotion;
- object absence does not become scarcity;
- AI-readable files do not become commerce SEO;
- no dashboard, funnel, or analytics language appears.

Observation can lead to restraint repair only.

## AI Army Commerce Preparation

Allowed agent roles:

- object continuity agent;
- wording thinning agent;
- semantic consistency agent;
- supply note organizer;
- commerce drift reviewer.

Forbidden agent roles:

- sales agent;
- growth agent;
- recommendation agent;
- funnel optimizer;
- autonomous merchandiser.

Capability without commerce restraint is a drift risk.

## Windkeep Continuity

Windkeep may become object circulation only if it stays human and low-pressure.

Allowed:

- objects moving by human correspondence;
- previous presence retained as quiet memory;
- low-frequency circulation;
- plain mail coordination.

Forbidden:

- marketplace logic;
- bidding;
- rankings;
- popularity;
- social commerce;
- transaction theater.

## Rule

Quiet commerce succeeds when an object can move from page to human life without the site behaving like ecommerce.
