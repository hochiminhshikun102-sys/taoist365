# 物体融入房间（Object Room Assimilation）

## 意图

Objects 从 catalog 主角退为 **房间结构**：少 spotlight、少重介绍、少 catalog 腔；允许「无 prose 日」与更激进的说明退休。

## 代码

- `src/data/object-room-dissolution/*` → `worldDefaultExistence.objectRoomDissolution`

## UI

与 `worldPostProductContinuity` 的 object 背景、`permanencePass` 叠加；`RealObjectPresencePanel` / `ObjectPermanenceStrip` 读取 **`invisibleInfrastructureStructuralThinning.combinedProseBias`** 与 `objectNonDisplayPresenceDay`。
