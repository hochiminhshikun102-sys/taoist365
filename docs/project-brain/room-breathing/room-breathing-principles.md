# Room breathing principles（房间呼吸原则）

## Core

Pages are **slow environments**: ultra-low-frequency ambient drift — not animation shows.

## Allowed

Very slow shifts in tone/light/atmosphere tied to time-of-day keys.

## Forbidden

High-frequency state churn, spectacle motion, glance-catching loops.
