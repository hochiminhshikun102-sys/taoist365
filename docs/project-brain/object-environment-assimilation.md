# Object environment assimilation

## Why objects become room infrastructure

When a catalog stops behaving like a storefront, artifacts read as **shelves**: familiar, peripheral, slow to change. That reduces “browse me” gravity without deleting the fact of physical things.

## What ships in code

- `src/data/object-environment-absorption/*` — copy lines for blending, passive contact, default surfaces.
- UI: `RealObjectPresencePanel`, `ObjectPermanenceStrip` use **`invisibleInfrastructureStructuralThinning`** with `objectRoomDissolution` and `permanencePass` so foreground narrows and prose thins on high bias days.

## Not allowed

Retro-web cosplay, fake analog nostalgia, cinematic browser melancholy.
