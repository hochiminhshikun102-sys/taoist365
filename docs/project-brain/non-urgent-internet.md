# Non-Urgent Internet

## Definition

**Non-urgent internet** (for Taoist365) means: **reopen without purpose**, **no need to finish**, **no chase to return**—aligned with `worldRegulation.attentionWithdrawal` but framed as **browser habit**, not therapy.

## Data

- `browserReality.reopen`, `returnWithoutPurposeLine`, `nonUrgentReopenLine`
- `reopenMood` enum: `passingThrough`, `idleReturn`, `nightCheck`, etc.—deterministic from `dayKey` only.

## Principles

- **Flat affect**: ordinary sentences; no poetry, no nostalgia filter.
- **Not** anti-retention as emotional manipulation—just **no task**.

## UI

- `LivingDailyBand` (sparse deterministic block), Guidance session when passive (exit copy, optional `noNeedToFinishLine` when noticing is empty).
