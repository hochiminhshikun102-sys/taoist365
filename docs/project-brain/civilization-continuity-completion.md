## Civilization Recovery Protocol

If semantic corruption, governance drift, feed mutation, emotional AI mutation, platform contamination, or optimization runaway appears:

1. Stop expansion.
2. Name the drift.
3. Compare against the civilization core.
4. Restore constitution anchors.
5. Restore wording DNA.
6. Restore Browser Air principles.
7. Restore semantic continuity.
8. Remove drifted behavior or wording.
9. Run `npm run guardrail:continuity`.
10. Run `npm run guardrail:kernel`.

Recovery favors rollback over clever repair when the drift is structural.
