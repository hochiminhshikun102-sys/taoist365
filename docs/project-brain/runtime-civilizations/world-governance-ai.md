# World governance civilization（世界治理文明）

## QUICK CONTEXT BOOTSTRAP

此文明 **不是** workflow（工作流）、**不是** orchestration pipeline（编排流水线）、**不是** agent。**runtime civilization** 指：在数据中固化的一组 **governance definitions（治理定义）**，对世界尺度边界说话，而非对用户指挥。

## WHY THIS CIVILIZATION EXISTS

承载 **`worldGovernance`** / regulation 与 anti-productization 章程，使任何通道扩张时仍有 **final override**（见 `governance-priority-system.md`）。

## WHAT IT PROTECTS

- Silence budgets、cross-cutting caps、anti-feed / anti-SaaS posture。
- **Terminal thinning discipline**：UI 只认 **`invisibleInfrastructureStructuralThinning`**。

## WHAT IT MUST NEVER BECOME

- 可视化治理面板、合规碎碎念 footer、「你被治理了」式 meta copy。

## PASSIVE VS ACTIVE BOUNDARIES

- **Passive**：默认阈值、变薄链、缺席矩阵。
- **Active（禁用）**：实时策略 UI、人工开关叙事、对访客可见的「模式切换」。

## LONG-LIVED GOVERNANCE

治理优先于增长；文案随年变薄而非变吵。

## FAILURE MODES

治理被 commerce 叙事覆盖；或治理宣言化导致「系统化」体感。

## DRIFT SIGNALS

出现 onboarding、streak、assistant shell、growth language — 见 `drift-detection/productization-drift.md`。

## INTERACTION WITH OTHER CIVILIZATIONS

压制 **commerce-ai**、约束 **guidance-ai** 的对话冲动；为 **environment-ai** 提供 URL quiet 上限。

## STRUCTURAL RESTRAINT RULES

硬闸优于 thinning；thinning 优于新 copy slot；**禁止**组件读取 **`civilizationStabilizedStructuralThinning`** 作为终端氛围依据。
