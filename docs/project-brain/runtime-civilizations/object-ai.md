# Object civilization（物象文明）

## QUICK CONTEXT BOOTSTRAP

物象层文明定义 **room structure（房间结构）** 而非 catalog（目录）。不是推荐引擎，不是「好物 workflow」。

## WHY THIS CIVILIZATION EXISTS

使 `/objects` 长期可读作家具与静置物，而非卖场。

## WHAT IT PROTECTS

- Foreground caps、prose thinning、`combinedProseBias` 下的隐身窗口。

## WHAT IT MUST NEVER BECOME

- SKU 叙事、打卡收集、社交展示墙。

## PASSIVE VS ACTIVE BOUNDARIES

- **Passive**：低频出线、沉积触感。
- **Active（禁用）**：筛选漏斗叫卖、对比导购。

## LONG-LIVED GOVERNANCE

物像 aging（老化）增厚 quiet，而非促销节律。

## FAILURE MODES

Catalog 感回升、「展品」语气主导。

## DRIFT SIGNALS

Foreground 物体数量膨胀、文案 operations 化 — `drift-detection/productization-drift.md`。

## INTERACTION WITH OTHER CIVILIZATIONS

与 **commerce-ai** 互抑：商业 signal 不得抬高物象叫卖。

## STRUCTURAL RESTRAINT RULES

仅以终端 thinning + regulation ids 交会；禁止宣言式「本层文明运行中」。
