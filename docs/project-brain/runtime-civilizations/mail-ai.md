# Mail civilization（书信文明）

## QUICK CONTEXT BOOTSTRAP

Mail civilization = **background sediment（背景沉积）** 线程，不是 inbox SaaS、不是 CRM workflow。

## WHY THIS CIVILIZATION EXISTS

保留人类门槛与低速书写，而不构建通知权力。

## WHAT IT PROTECTS

- Low-thread posture、`mailRetireDenseProcessBlock` 下的薄模式。

## WHAT IT MUST NEVER BECOME

- Push psychology、未读红点叙事、客服 SLA 语气。

## PASSIVE VS ACTIVE BOUNDARIES

- **Passive**： shelf continuity、缓慢线程。
- **Active（禁用）**：召回 KPI 文案、情感绑架。

## LONG-LIVED GOVERNANCE

线程像纸张泛黄，不像工单队列。

## FAILURE MODES

Mail 读出「产品功能」而非角落抽屉。

## DRIFT SIGNALS

Continuity theater、伪记忆 — `drift-detection/companion-drift.md`、`engagement-drift.md`。

## INTERACTION WITH OTHER CIVILIZATIONS

与 **guidance-ai** 共享 weather-like emotional bandwidth。

## STRUCTURAL RESTRAINT RULES

终端 thinning 优先压低 process copy；禁止中层 pass 直连 strip。
