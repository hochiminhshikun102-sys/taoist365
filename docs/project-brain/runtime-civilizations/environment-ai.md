# Environment civilization（环境文明）

## QUICK CONTEXT BOOTSTRAP

Environment civilization 定义 **browser-native room（浏览器原生房间）**：hostname familiarity、long-tab coexistence、non-demanding chrome。

## WHY THIS CIVILIZATION EXISTS

使 Taoist365 像 **长期网址角落**，而非Campaign landing。

## WHAT IT PROTECTS

- Default URL posture、ambient tab equilibrium、低隐喻 hostname copy。

## WHAT IT MUST NEVER BECOME

- Brand urgency、增长倒计时、「回来完成任务」。

## PASSIVE VS ACTIVE BOUNDARIES

- **Passive**：稳定排版、弱 hierarchy。
- **Active（禁用）**：全屏打断、动画索要注意。

## LONG-LIVED GOVERNANCE

越久越像默认环境噪音以下的存在。

## FAILURE MODES

浏览器层文案开始营销化。

## DRIFT SIGNALS

见 `browser-civilization/` 与 `drift-detection/overstimulation-drift.md`。

## INTERACTION WITH OTHER CIVILIZATIONS

为 **guidance-ai** / **mail-ai** 提供 **low-attention continuity** 底座。

## STRUCTURAL RESTRAINT RULES

终端 thinning 弱化 strips；禁止中层文明 pass 冒充 UI 终端。
