# Commerce civilization（商业文明）

## QUICK CONTEXT BOOTSTRAP

**Low-signal commerce civilization** — 商业行为只允许以 **infra vocabulary** 与终端 thinning 压低后的 slot 存在；**不是** monetization funnel（变现漏斗）文明。

## WHY THIS CIVILIZATION EXISTS

预埋 restraint，使未来 commerce 接入仍服从治理栈。

## WHAT IT PROTECTS

- Anti-conversion pressure、fulfillment backgrounding、quiet transaction grammar。

## WHAT IT MUST NEVER BECOME

- Recommendation engine、gamification、CRM workflow、growth dashboard。

## PASSIVE VS ACTIVE BOUNDARIES

- **Passive**：静默履约叙述、物体层低速提及。
- **Active（禁用）**：倒计时抢购、个性化推送话术。

## LONG-LIVED GOVERNANCE

商业像后勤，不像前台演艺。

## FAILURE MODES

Commerce signal 抬高吃掉 quiet equilibrium。

## DRIFT SIGNALS

见 `drift-detection/high-signal-commerce-drift.md`。

## INTERACTION WITH OTHER CIVILIZATIONS

**world-governance-ai** 与 **object-ai** 对其拥有否决张力。

## STRUCTURAL RESTRAINT RULES

任何 commerce copy 必须经过终端 thinning 链；禁止绕过 regulation。
