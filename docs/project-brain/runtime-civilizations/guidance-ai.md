# Guidance civilization（指引文明）

## QUICK CONTEXT BOOTSTRAP

**Not agents.** Guidance civilization = weather-first、session-shaped **without** chat closure 的数据口径；由 dissolution + quiet + **terminal thinning** 共同执行。

## WHY THIS CIVILIZATION EXISTS

把 guidance 从「应答」扭转为 **room weather（房间天气）**，降低 interaction-shaped reading。

## WHAT IT PROTECTS

- Non-resolution stability、anti-session gravity。
- Routes / closure copy 在高 bias 日硬化关闭（由 **`invisibleInfrastructureStructuralThinning`** 触发）。

## WHAT IT MUST NEVER BECOME

- Copilot session、therapy simulation、companion rapport。

## PASSIVE VS ACTIVE BOUNDARIES

- **Passive**：天气句、notice line 上限、quiet rhythm。
- **Active（禁用）**：多轮追问脚本、任务完成庆祝。

## LONG-LIVED GOVERNANCE

越久越像气候，不像客服。

## FAILURE MODES

Weather stack 仍读起来像「AI 在带你走完流程」。

## DRIFT SIGNALS

Closure  obligatory、route 强迫、micro-interaction 密度上升 — `drift-detection/over-interaction-drift.md`。

## INTERACTION WITH OTHER CIVILIZATIONS

服从 **world-governance-ai**；与 **environment-ai** 共享 low-attention defaults。

## STRUCTURAL RESTRAINT RULES

Guidance 组件 **仅**消费终端 thinning；中间文明 pass 不得直达 UI。
