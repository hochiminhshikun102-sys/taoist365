# Anti-Performance Layer

## Intent

Prevent Taoist365 from **performing** restraint — the aesthetic of “we are so quiet” that reads as another product mode.

## Implementation

- **`antiPerformanceReminder`** on `WorldRegulationBundle`, from `anti-performance-runtime.ts`.
- Shown **rarely** and only as muted footer-class copy (deterministic day key modulo in Guidance; similar policy in `WorldRegulationPresenceStrip` on Home/Objects).

## Tone rules (product)

- Plain, slightly boring, **non-meta** about the site’s intelligence or wisdom.
- No digital monastery cosplay, no slow-web elitism, no cinematic silence as flex.

## Banned postures (for copy and layout)

- “This site knows it is quiet.”
- Self-aware minimalism as brand.
- Pseudo-intellectual residue.
- Aware prose that comments on the interface being sparse.

If new copy sounds like **about the design** rather than **about the room**, send it through this filter.
