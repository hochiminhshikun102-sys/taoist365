# Default environment governance

## QUICK CONTEXT BOOTSTRAP

- Governance here is **how defaults are chosen**, not how users are coached.
- The civilization layer encodes “this should feel normal” through thinning, caps, and retirement—without stating it on-page.

## THIS DOCUMENT DEFINES

How **`worldGovernance`**, **`worldEcologyCalibration`**, and **`worldCivilizationStabilization`** sequence to produce **ordinary, low-friction** surfaces.

## CORE PRINCIPLES

- **Defaults beat prompts**: if something must change behavior, change thresholds—not add wizard copy.
- **Background-first wins**: Home hierarchy weakens under combined thinning; strips stay sparse on pressure days.
- **Hard gates respected**: regulation and structural absence remain absolute; thinning only operates where visibility is still allowed.

## CODE ANCHOR

- Resolution order: `useWorldRuntime()` tail in `src/lib/use-world-runtime.ts`.
- Docs: `world-governance.md`, `world-ecology-calibration.md`, `runtime-society.md`, `ambient-civilization-equilibrium.md`.

## WHY GOVERNANCE SHOULD FEEL INVISIBLE

Visible governance reads as **product authority**. Invisible governance reads as **room manners**—the intended posture for Taoist365.

## MAINTENANCE NOTES

- Log material governance changes in `decisions-log.md`; keep `anti-productization-rules.md` in sync when tightening thinning.
