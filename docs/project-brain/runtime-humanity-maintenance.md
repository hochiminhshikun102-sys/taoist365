# Runtime humanity maintenance（运行时人性维护）

**Mode:** COPY IS NO LONGER PRIMARY — humanity reads through layout, not prose.

## Where humanity lives

- Spacing softness (`runtime-room-shell` utilities, section cadence)
- Room density and object resting surfaces (`object-resting-surface`, `room-object-stack`)
- Browser-native calm (no blur theatrics, quiet loading)
- Reading air (short lines, few stacked explanations)
- Silence as **absence of atmosphere copy**, not quoted stillness

## Do not add

- Quiet wisdom, gentle reminders, reflective layering, soft-thought framing
- Worldbuilding prose that **describes** the site’s mood
- Poetic interface syndrome (“beautiful sadness,” literary calm)

## When copy is allowed

- Plain utility: how to mail, what a route is, boundaries that prevent harm
- Single-sentence orientation — never stacked emotional narration

## Drift check

- If a page **reads** like it is explaining its own atmosphere → collapse copy and rely on spacing.
- If Objects reads like a brand manifesto → remove preamble; keep title, placement, photo, mail path.

## Data silence era (runtime)

- Daily band and session banners do **not** stack world-runtime prose.
- Inertia lines are **status-sized**, not literary.
- Reflection prompts may resolve to **blank glyphs** (`—`) instead of coaching questions.
