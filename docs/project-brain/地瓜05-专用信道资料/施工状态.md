## 固定施工规则

- 素材唯一存放到 D 盘项目内。
- `public` 只放网页运行必须加载的压缩图、SVG、CSS 相关资产。
- PSD、坐标文档、效果图、源图、参考图放到源素材目录，不进 `public`。
- 网页运行图默认使用 WebP。
- 不使用整页超大 PNG 做网页；按层拆图、压缩、组件化施工。
- 轮播图不要一进入页面全部加载，优先加载当前屏。
- 移动端不能锁死 375px；iPhone 390/414/430 宽度必须满屏。
- 手机端雨声、音乐等有声内容必须用户点击后播放，不能自动有声播放。
- 动态效果优先用轻量 CSS/canvas：风、飘纱、雨、烛光、叶子、花瓣等。

- 首屏资源优先加载，后续层懒加载或轻量加载。
