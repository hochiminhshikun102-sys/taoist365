# Browser Reality Engine

## What “browser reality” means

**Browser reality** is the layer that describes Taoist365 as **hostname + tab + history + autocomplete**—things the **browser** owns—not as a product that “serves” or “updates” the user.

It is day-deterministic, has **no access** to visit counts or identity, and never implies the server “remembers” you.

## Implementation

- Path: `src/data/browser-reality-engine/`
- Root: `resolveBrowserRealityBundle(structuralSilence, worldRegulation, aging, inertia, worldStability)` in `system.ts`
- Wired on `useWorldRuntime()` as **`browserReality`**, resolved **after** `worldStability` governance (stability supplies `foregroundFriction` for object sediment narrowing).
- **Downstream:** `runtimeRetirement` uses **`worldStabilityEngine.engineStabilityScalar`** and **`browserReality.objectInternetSediment`** for object rare foreground and guidance retirement; `ObjectRuntimeGate` chains **regulation → sediment → `rareForegroundObjects`**.

## Bundle highlights

| Area | Intent |
|------|--------|
| Long tab | Tab persistence states, plain lines: open long, not a reminder, not waiting. |
| Hostname | Familiarity with **URL shape**, not “brand greatness.” |
| Reopen | Moods for **return without purpose**—no finish line required. |
| Old URL / browser aging | Stable structure, thicker **browser-side** habit—not retro cosplay. |
| Background / forgotten tab | Site as **background resident**, not interaction-waiting. |
| Browser silence | Passive co-existence: long pause is legitimate, not idle timeout UX. |
| Ambient revisit | Same lines can recur **without tracking**—like bookmark residue. |
| Object internet sediment | Narrows **`sedimentForegroundIds`** from regulation list—foreground scarcer, not full catalog. |
| Guidance passive surface | Some days session behaves as **passive open state** (see `passive-open-states.md`). |
