# Long-Term Browser Civilization Infrastructure

This is the infrastructure handoff for Reverent Inquiry as a long-lived browser civilization. It is not a product roadmap and does not authorize new pages, runtime ecology, organisms, app shells, dashboards, or atmosphere expansion.

## Infrastructure Posture

The default maintenance posture is freeze-compatible: preserve what is stable, remove pressure, automate boundaries, and keep production surfaces ordinary.

Infrastructure means:
- executable guardrails over memory in chat
- production stability over experimentation
- archive isolation over public source packs
- browser persistence over app behavior
- low-pressure systems over engagement logic
- continuity handoff over session-specific instructions

## Automation Layer

Required commands:
- `npm run guardrail:terminology`
- `npm run guardrail:governance`
- `npm run guardrail:infrastructure`
- `npm run guardrail:runtime`
- `npm run guardrail:operating`
- `npm run guardrail:kernel`
- `npm run lint`
- `npm run build`

The guardrail checks terminology drift, production path drift, production asset continuity, public archive isolation, required package scripts, required governance anchors, and production brand references.

Runtime infrastructure is governed by `npm run guardrail:runtime`, which freezes runtime budgets, `useWorldRuntime()` top-level fields, required runtime files, and runtime hierarchy anchors.

Operating continuity is governed by `npm run guardrail:operating`, which runs the infrastructure and runtime guardrails as one low-complexity operating check.

Continuity kernel stability is governed by `npm run guardrail:kernel`, which runs the operating layer and confirms the recoverable kernel memory paths.

## Continuity Roles

Windkeep infrastructure supports object passage, shelf continuity, keeper traces, ordinary persistence, Quiet Receiving, and low-pressure stewardship. It must not become marketplace backend, collectible logic, inventory behavior, auction energy, checkout flow, or ownership pressure.

Driftbox infrastructure supports sparse continuity, unresolved drift, low-frequency intelligence, and browser-current feeling. It must not become an AI assistant system, chatbot loop, productivity helper, reply engine, or interaction addiction surface.

The Courier infrastructure supports quiet organism continuity: lightly irregular, browser-native, low-attention, and subtly persistent. It must not become a dashboard system, feature creep channel, utility layer, gamified surface, or attention competitor.

Pocket Browser infrastructure supports phone-browser air: stable, low-density, scrollable, and reality-compatible. It must not become an app shell, mobile product funnel, feed, retention system, install prompt, or assistant UI.

## Reality Compatibility

Reality Compatibility means Reverent Inquiry remains beside ordinary life rather than becoming a digital cocoon.

Avoid:
- emotional dependency
- assistant gravity
- sanctuary drift
- therapeutic behavior
- comfort engineering
- productivity system creep
- AI attachment patterns

Keep:
- ordinary exits
- mail as slow human route
- browser-held persistence
- no accounts as default
- no reminders or hooks
- no pressure to return
