# Governance priority system（世界治理优先级）

## QUICK CONTEXT BOOTSTRAP

正式定义：**WORLD GOVERNANCE AI** 在此文档中指 **`world-governance-layer`** + **`world-regulation-engine`** + structural silence 硬闸所构成的 **governance stack（治理栈）** — **不是**聊天机器人，**不是** agent。**Final override authority（最终否决权）** 属于：**restraint（克制）**、**silence（沉默）**、**environmental equilibrium（环境均衡）**、**low-signal continuity（低信号连续性）**、**anti-productization（反产品化）**。

## Priority lock（优先级锁定）

**Softness without extraction（不索取的柔软）** — 见 `softness-without-extraction/softness-without-extraction.md` — 与下列条款 **同级宪法**：温度仅在环境，禁止情绪剥削。

下列目标 **永远优先于** commerce（商业）、engagement（参与度）、growth（增长）、monetization（变现）、raw AI capability（裸 AI 能力）、personalization（个性化）：

1. **Structural absence & regulation gates** — 硬缺席与调控上限不被绕过。
2. **Thinning chain terminal** — UI **仅**读取 **`invisibleInfrastructureStructuralThinning`**；中间层不得冒充终端。
3. **Anti-companion & anti-feed constitution** — 见 `anti-companion-governance.md`、`anti-productization-rules.md`。
