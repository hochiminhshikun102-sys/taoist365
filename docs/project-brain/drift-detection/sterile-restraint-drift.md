# Sterile restraint drift（无菌克制偏移）

## Symptoms

Design becomes **correct but uninhabitable** — praise for purity, silence reads as refusal.

## Checks

- [ ] Any surface feels like a gallery placard?
- [ ] Copy avoids all mundane verbs?
- [ ] Motion budget → zero everywhere?
