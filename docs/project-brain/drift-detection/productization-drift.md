# Productization drift（产品化偏移）

## Purpose

监控 Taoist365 是否滑向传统 **product（产品）** 形状。

## Drift Signals Checklist

- [ ] 新 surface 使用 onboarding、wizard、进度条叙事
- [ ] 出现 dashboard、account、settings 扩张冲动
- [ ] Copy 出现「功能」「版本更新」「为你优化」式运营语气
- [ ] UI 层级变深、模块命名扩张（宣称系统化）
- [ ] 组件绕开终端 thinning 直连中层 pass（术语层违规）

## Mitigation

回到 **`invisibleInfrastructureStructuralThinning`** 与 `governance-priority-system.md`。
