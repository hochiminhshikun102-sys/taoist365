# Companion drift（陪伴化偏移）

## Purpose

监控 **parasocial / companion** 倾向。

## Drift Signals Checklist

- [ ] 文案暗示「我在等你」「想念」「只有你」
- [ ] 拟记忆、关系昵称、亲密称谓
- [ ] 情绪 escalation 脚本、疗愈扮演
- [ ] Continuity / comeback 语言绑架（visitor-facing；不含技术性 `continuity-engine` 模块名）

## Mitigation

`anti-companion-governance.md`；缩减交互回合密度。
