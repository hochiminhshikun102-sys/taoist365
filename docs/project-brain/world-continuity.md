# World Continuity

## Charter

The world should read as **never having gone offline** between visits: same URLs, same cross-page shape, revisit without event, autocomplete familiarity—**without** “welcome back” or last-visited theater.

## Code

- `src/data/world-continuity-engine/*`
- `worldPostProductContinuity.continuity`

## Boundaries

Only **browser-side** metaphors; no session continuity, no account memory.
