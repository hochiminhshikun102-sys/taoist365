# Restrained warmth index（克制温度指数｜CTI 锚）

## Purpose

**Civilization Temperature Index (CTI)** — qualitative gauge: is the URL **too cold**, **too hot**, **too AI**, **too sacred**, **too hollow**?

## Target band

**Restrained warmth equilibrium** — inhabit silence without sterility; warmth without extraction.

## Scale (internal)

| Zone | Read |
|------|------|
| CTI −2 | Cold temple / museum |
| CTI −1 | Clean but thinning humanity |
| **CTI 0** | **Target band** |
| CTI +1 | Warm copy creep / soft manipulation risk |
| CTI +2 | Companion / engagement drift |
