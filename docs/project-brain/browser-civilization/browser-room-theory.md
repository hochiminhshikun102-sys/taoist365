# Browser room theory（浏览器房间理论）

## Definition

**Browser room**：浏览器窗口 = 容器；本站 = 房内陈设与气候；访客注意力 = 偶尔落在室内的光线。**不是** SaaS dashboard room。

## Five axioms

1. **Long-tab legitimacy** — 长期不关标签是正常，不是「流失」。
2. **Non-demanding surfaces** — 界面不要求进度。
3. **Environmental continuity** — continuity 是世界状态函数，不是用户画像函数。
4. **Low-awareness emotional weather** — 情绪表达像天气变化，不像客服跟进。
5. **Governance overrides spectacle** — 治理栈高于任何展示欲。

## Interaction with thinning

终端 **`invisibleInfrastructureStructuralThinning`** 负责削弱 hierarchy 与 strips，使「房间」不被模块条切碎。

Assistant framing、orchestration visibility、platform 叙事 — 见 `terminology-governance.md`、`anti-companion-governance.md`。
