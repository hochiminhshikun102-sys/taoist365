# Low-attention environment（低注意环境）

## Purpose

页面默认为 **low-attention continuity**：背景情绪天气式波动，而非交互回合。

## Principles

- **Background emotional weather**：情绪纹理淡、低频。
- **Environmental coexistence**：与其他标签页和平共处。

## UI rule

避免动画与强调诱导高频扫视 — `overstimulation-drift.md`。

## Terminology

禁用 growth / engagement / 用户旅程等词汇；用 **quiet participation**。
