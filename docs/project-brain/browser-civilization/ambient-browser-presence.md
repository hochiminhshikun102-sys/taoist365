# Ambient browser presence（环境型浏览器在场）

## Purpose

定义 Taoist365 作为 **long-lived tab（长期标签）** 时的 **ambient presence（环境型在场）**：不索取 focal attention（焦点注意），允许后台共存。

## Browser room link

属于 **browser room theory** 的外层：浏览器 chrome + 本站弱 hierarchy 共同形成「房间空气」。

## Drift signals

页面开始要求「每次打开都完成一步」— 见 `drift-detection/over-interaction-drift.md`。

## Vocabulary

使用 **environmental presence**、**coexistence**，避免 assistant / journey / 留存话术。
