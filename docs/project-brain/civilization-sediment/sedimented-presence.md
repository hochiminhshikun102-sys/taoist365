# Sedimented presence（沉积型在场）

## Definition

**Sediment（沉积）**：时间留下的薄层 — 灰尘、纸黄、触摸痕 — **不是** timeline 事件流。

## vs memory system

禁止 visitor profile memory；允许 **environmental sediment（环境沉积）** — deterministic world-age residue。

## UX goal

用户感到 **「房间住久了」**，而非「数据库记住我」。
