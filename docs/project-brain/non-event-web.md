# Non-Event Web

## Charter

The site avoids **event energy**: no launches, campaigns, content calendars, or “something happened today” framing. Pages feel **long-open** and **unchanged-comfort**, not staged idleness.

- `src/data/non-event-internet-layer/*`
- `worldPostProductContinuity.nonEvent`

## Forbidden tone

Vintage nostalgia, indie-web cosplay, fake retro UI.
