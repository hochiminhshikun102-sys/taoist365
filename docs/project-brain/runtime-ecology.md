# Runtime ecology

## Why runtimes must suppress each other

If every channel speaks at full volume, the page becomes an app. Ecology means **mutual limits**: guidance bias can thin mail residue the same day; fatigue can thin all prose; structural silence retires stacks first.

## Code

- `src/data/runtime-ecology-engine/*` — vocabulary for overlap, retreat, and quiet priority.
- Numeric coupling: `extreme-governance-thinning-pass.ts` (fatigue / pageEnergy / absence) and **`extreme-ecology-calibration-thinning-pass.ts`** (fragmentation / breathing / foreground / permanence bias)—see `world-ecology-calibration.md`.

## Precedence

Hard gates (`structuralAbsence`, `sectionMatrix`) still win over thinning ORs—ecology tightens thresholds, it does not invent new chrome.
