# Long-Lived Site Behavior

## Role

Describes **how** the stack models a site that has been open for years: tab persistence, hostname habit, sections that rarely change, mail as sediment—not features, but **posture** shared by `quiet-internet-permanence`, `browser-reality-engine`, `low-refresh-internet`, and `worldQuietPermanence`.

## Boundaries

- No staged retro, no webcore, no fake old-internet cosplay.
- Deterministic copy only; no analytics-driven behavior.
