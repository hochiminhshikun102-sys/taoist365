# Softness without extraction（不索取的柔软）

## Constitutional rank

本目录与 **`governance-priority-system.md`**、**`anti-companion-governance.md`** 同级锚点：定义 Taoist365 **最高文明宪法**之一 — **有温度的环境，零情绪剥削**。

## Definition

- **Softness** lives in **material**: spacing, light, copy cadence, slow rhythm — not in persuasion or caretaking performance.
- **Without extraction** means: no hooks that harvest loneliness, guilt, urgency, or attachment.

## Hard bans

- 「在等你」「欢迎回来想你」「你需要我」「只有我懂你」类叙事。
- 将温柔 **对准用户情绪按钮** 的任何产品语法。
