# Humanity without retention（人性但不留存机器）

## Definition

Human warmth **does not justify** retention mechanics: streaks, comeback theater, guilt gaps, pseudo-memory hooks.

## Implementation stance

Continuity = **environmental** (same URL, same quiet defaults), not **relational**.
