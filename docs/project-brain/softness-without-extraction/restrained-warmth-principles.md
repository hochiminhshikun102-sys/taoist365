# Restrained warmth principles（克制温度原则）

## Principle

Warmth is **under-stated**: felt as room, not as persona.

## Allowed

- Neutral-warm palettes, generous margins, plain verbs.
- Occasional domestic nouns (tray, sill, lamp) without storytime.

## Forbidden

- Enthusiasm spikes, hype cadence, cheerleading, emotional inflation.
