# Environmental equilibrium

## Why the world needs a “governor” toward environment

Without a governor, thinness and silence compete randomly. A single composed layer (`world-environmental-equilibrium` bundle inside `worldAmbientInternet`) holds **language** for restraint: less UI voice, less structure narration, more backgrounding. Numeric pressure still comes from existing **`quietEquilibrium.equilibriumPressure`** feeding both base and extreme thinning passes.

## Code paths

- `src/data/world-environmental-equilibrium/*` — restraint, thinning engine, backgrounding lines.
- `resolveAmbientStructuralThinningPass` consumes `equilibriumPressure` from `worldDefaultExistence.quietEquilibrium`.
