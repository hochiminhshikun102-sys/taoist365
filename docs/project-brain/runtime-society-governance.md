# AI runtime society governance（AI 运行时群落治理）

## 快速对齐

- **Runtime society（运行时群落）**：多个 bundle 像群落一样长期共存；**自治（autonomy）** 体现在它们通过 pressure / fatigue / silence diplomacy（沉默协商）等语言自我压低，而不是中央 UI 指挥。
- 本包 **`ai-runtime-society-governance`** 与上一阶段的 `runtime-society-engine` 互补：后者偏文明稳定，这里偏 **AI-native infra** 下的自治语气。

## 本文件定义什么

回答：为何 runtime 最终必须 **「自治但受治理」**—自治负责在日常尺度退让与协商；治理负责不可逾越的红线（anti-companion、anti-feed 等）。

## 核心原则

1. **不像 feature（功能）**：群落行为应读起来像背景张力，不像产品模块列表。
2. **Foreground collapse（前台坍塌）** 优先于解释为何坍塌。
3. **红线**：runtime 互骂、互引战式 meta prose 禁止；保持「无名协作」。
