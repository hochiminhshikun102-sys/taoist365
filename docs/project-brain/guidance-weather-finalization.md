# Guidance weather finalization

## QUICK CONTEXT BOOTSTRAP

- Guidance should read as **ambient condition** (weather-like), not as dialogue, closure, or session arc.
- Finalization means **passive weather bias** can win often: single line, no route, no closure—without looking broken.

## THIS DOCUMENT DEFINES

The guidance-facing civilization bundles that bias **`GuidanceSessionClient`** toward weather-only stacks through **`invisibleInfrastructureStructuralThinning`**（final pass）.

## CORE PRINCIPLES

- **Weather over conversation**: routes and closure copy retire under combined thinning bias, not via new UI modes.
- **Coherence without chat**: dissolution + quiet bundles stay authoritative; civilization adds **extra pressure** on high-friction days.
- **Readable emptiness**: when stacks collapse to minimal copy, spacing and rhythm should still feel intentional.

## CODE ANCHOR

- `src/data/guidance-weather-finalization/` in `world-civilization-stabilization-layer`.
- Integration: `GuidanceSessionClient` reads **`worldAiNativeInfrastructure.invisibleInfrastructureStructuralThinning`**.

## WHY GUIDANCE MUST BECOME WEATHER

Dialogue-shaped guidance scales into **product obligation** (turns, resolutions, memory theater). Weather-shaped guidance scales into **background**: it can be present without demanding a response.
