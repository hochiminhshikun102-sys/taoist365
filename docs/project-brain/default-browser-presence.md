# Default browser presence

## Why defaultness beats brand theater

Long-lived sites win when the hostname feels **unremarkable**—a place you return to without ceremony. That is `browser-default-air`, not a launch narrative.

## What ships in code

- `src/data/long-lived-internet-defaultness/*` — hostname air, passive URL habit, non-event return.
- Composed into `worldAmbientInternet`; pairs with `browser-reality-engine` and `internet-defaultness-engine` without duplicating routes or features.

## Not nostalgia

Endurance without retro cosplay; stability without saying “we are stable.”
