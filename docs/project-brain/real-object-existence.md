# Real Object Existence

## Purpose

Objects behave like **things in a room**, not infinite catalog rows: quiet retirement, shelf thinning, temporary absence, material imperfection—**without** scarcity marketing (`sold out`, `low stock`, `hurry`). Data: `src/data/real-object-presence/` → `worldMaturity.realObjectPresence`.

## Language guardrails

- Prefer: “haven’t seen that cup lately,” “that linen batch wore thin,” “the wood tray hasn’t been back on the shelf.”
- Reject: e-commerce urgency, stock pressure, conversion hooks.

## Bundle surface

Lines for availability echo, small-batch aging, quiet retirement, shelf thinning, disappearance, imperfection, ownership transfer metaphor, storage reality, rest state; optional `catalogEchoLine` from a deterministic catalog pick + day key.

## Real world entry (`worldMaturity.realWorldEntry`)

Companion lines: desk habit, mail-to-room transition, ordinary use, forgetfulness, object no longer “special”—same ban on acquisition theater. Resolved in `src/data/real-world-entry/`.

## UI

- `RealObjectPresencePanel` on `/objects` beside existing material and correspondence blocks (merges shelf reality + a `realWorldEntry` line).
