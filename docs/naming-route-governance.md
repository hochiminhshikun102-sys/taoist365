## Language and Metadata Guardrails
All route metadata, page titles, and OpenGraph entries must remain:
- calm
- ritual-oriented
- grounded
- non-startup
- non-assistant
- non-occult
- non-marketing pressure

## Disallowed Naming Drift
- AI assistant framing
- fortune-telling terminology as core identity
- startup growth language
- conversion-first page naming
- mystical spectacle wording

## Future Experience Route Pattern
Use product-layer naming with ritual context:
- `/prototype/draw-a-lot`
- `/prototype/daily-guidance`
- `/prototype/home-harmony`

Route labels should describe experience rhythm, not tool utility.
