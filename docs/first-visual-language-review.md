# First Visual Language Review

## Atmosphere Climate Checks
- [ ] Does the surface feel like a space, not a UI tool?
- [ ] Is there material calmness instead of polished tech sheen?
- [ ] Is warmth quiet and grounded rather than decorative?

## Tone Drift Checks
- [ ] Is there any startup minimalism drift?
- [ ] Is there any mystical spectacle drift?
- [ ] Is there any fake luxury pressure drift?

## Rhythm Checks
- [ ] Does reading rhythm feel breathable?
- [ ] Are section transitions calm and unhurried?
- [ ] Does hierarchy preserve emotional pacing?

## Emotional Effect Checks
- [ ] Can users pause naturally without pressure?
- [ ] Do visuals reduce agitation rather than raise it?
- [ ] Does the page evoke Taoist-inspired living rhythm?

## Prohibited Style Checks
- [ ] No black-gold mystical style
- [ ] No flashy premium visual spectacle
- [ ] No conversion-first visual aggression
- [ ] No SaaS polish mimicry
