# Memory Policy

## Allowed Scope
Short-term memory:
- session continuity
- recent ritual step continuity
- recent emotional context continuity

Long-term memory:
- lightweight preferences only (tone, ritual pace, preferred check-in cadence)

## Disallowed Scope
- deep personality modeling
- psychological profiling
- attachment optimization
- dependency relationship memory
- persona simulation memory

## Principle
Memory serves care continuity, not behavioral control.

## Retention Rule
Store minimum useful context. Remove details that are not required for continuity.

## Safety Trigger
If memory indicates dependency patterns, block response composition and downgrade to neutral safety guidance.
