# Approved Reverent Inquiry Symbols

Reverent Inquiry is now the front-facing brand identity.

Approved assets:

- `reverent-inquiry-air-mark.svg`: production browser-air symbol.
- `reverent-inquiry-air-mark-monochrome.svg`: approved one-color variant.
- `reverent-inquiry-air-mark-dark.svg`: approved dark-surface variant.
- `reverent-inquiry-logo-board.png`: locked logo system reference board.

Usage:

- Use the air mark as a supporting symbol beside the Reverent Inquiry wordmark.
- Keep `taoist365.com` as the domain and ecosystem anchor.
- Do not use Chinese typography, gold Taoist marks, spiritual seals, or old Yewen-era symbols in production UI.
