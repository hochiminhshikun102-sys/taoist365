# Visual Anti-Patterns

## Purpose
This document defines visual and interaction directions that Taoist365 must avoid to preserve its core identity as a Taoist-inspired lifestyle rhythm experience.

## Hard No List
- mystical overload
- black-gold pressure style
- glowing occult graphics
- dashboard card walls
- AI chat interface framing
- crypto/startup visual language
- dopamine UI patterns
- gamified interaction loops
- fortune teller aesthetics
- cluttered luxury
- aggressive CTA stacking

## Why These Are Rejected
These styles push users toward tension, urgency, and spectacle, which conflicts with Taoist365 principles:
- calm before conversion
- atmosphere before explanation
- ritual rhythm before feature consumption

## Positive Direction
Taoist365 visual language should feel:
- warm minimal
- breathable
- emotionally safe
- premium but quiet
- grounded and spacious

## Structural Design Checks
Before shipping any new surface, verify:
1. Is there enough visual silence?
2. Is primary action pressure low?
3. Does scroll rhythm include pauses?
4. Does reveal pacing respect user attention?
5. Does the page avoid tool/dashboard framing?
