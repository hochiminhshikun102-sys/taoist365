# Legacy Asset Audit (Manus Backup)

## Scope and Method
This audit reviews `manus-backup/` as a legacy asset library, not a migration source.

Reviewed sources:
- migration docs and environment notes
- extracted workspace code (`reverent-inquiry-dashboard`)
- homepage, oracle entry, draw-a-lot, shared module renderers
- AI guide/chat surfaces
- commerce and conversion-oriented components
- media/database backup manifests

Current Taoist365 baseline used for comparison:
- ritual rhythm and emotional pacing
- atmosphere-first interaction
- calm and non-marketing identity
- non-dependency language and boundaries

---

## Legacy Asset Map

### A) Architecture and Product Shape (Legacy)
- Stack: React + Express + tRPC + Drizzle + MySQL (Manus platform constraints)
- Product shape: hybrid of oracle + ecommerce + admin CMS + AI guide
- Home routing centered around dynamic CMS modules (`hero/grid/banner/product_grid/brand_story`)

### B) Homepage Structure (Legacy)
- Heavy hero carousel with autoplay and swipe
- Multiple conversion-oriented sections in one long page:
  - collections grid
  - oracle entry
  - shop-by-intention grids
  - product kits
  - testimonials
  - newsletter subscribe
- Strong CTA repetition and offer language

### C) Oracle / Draw-a-Lot Experience (Legacy)
- Includes sequential phases: idle -> shaking -> drawing -> result
- Contains interaction concept worth preserving (phase sequencing)
- Visual/tone execution is dramatic, promotional, and dense
- Result pages include product recommendations and monetization blocks

### D) Moon Block Confirmation
- No explicit moon-block (shengbei) confirmation flow found in audited files
- Must be designed fresh in Taoist365 rhythm model

### E) AI and Interaction Framing (Legacy)
- Dedicated AI guide page and chatbox patterns
- Assistant/chat framing appears in nav and key entry points
- ¡°wise assistant¡± system prompt style with commerce recommendation intent

### F) Visual and Tone Signature (Legacy)
- Dark brown + gold and glowing accents are widely used
- Luxury/mystical vocabulary appears frequently
- Several sections read as campaign/commerce-first

## KEEP / REBUILD / REJECT Classification

## KEEP (Reusable with minimal adaptation)
- **Phased ritual interaction scaffolding** from draw-a-lot (`idle/shaking/drawing/result`) as abstract state machine idea
- **CMS modular rendering concept** (module-based section composition), as a technical idea only
- **Data model idea for lot text + recommendation mapping** (structure, not UI behavior)
- **Localized bilingual capability approach** (future-ready internationalization concept)

## REBUILD (Direction useful, execution conflicts with current world)
- **Homepage section rhythm**: keep concept of narrative sections, rebuild into silence-first pacing
- **Draw-a-lot mechanics**: keep ritual sequence logic, rebuild visual rhythm and interaction timing to low-stimulus
- **Ask-the-oracle entry**: keep path clarity, rebuild as calm invitation instead of product matrix
- **Product-intention taxonomy**: keep information architecture, rebuild language and placement as atmosphere-first
- **CMS content blocks**: keep flexibility, rebuild templates to enforce calm-density and non-marketing rules
- **Trust and guidance messaging**: keep trust intent, rebuild with non-promotional voice system

## REJECT (Conflicts with Taoist365 worldview)
- **AI chatbox framing** and assistant-first entry points
- **Black/gold pressure and glowing mystical spectacle style patterns**
- **Conversion-heavy CTA stacks** (¡°Unlock now¡±, repeated action pressure, urgency cues)
- **Ecommerce-first homepage behavior** (grid walls, kit upsell density)
- **Dashboard/admin visual language bleed into user experience**
- **Prophecy/luxury-spiritual campaign tone** and mystical branding posture
- **Gamified or high-reactivity interaction moments** (fast shake energy and reward-like reveal mood)

## Interaction Extraction (for Taoist365 Re-adaptation)

### Draw-a-Lot Interaction Elements Worth Preserving
1. **Stateful ritual progression**
   - Preserve: distinct interaction phases
   - Adapt: longer settle and reflection windows

2. **Embodied action before result**
   - Preserve: user action precedes guidance
   - Adapt: reduce kinetic intensity and spectacle

3. **Layerable result model**
   - Preserve: result can be progressive
   - Adapt: enforce slow layered reveal, pause-before-next

4. **Reset / draw again affordance**
   - Preserve: optional repetition
   - Adapt: boundary-aware continuation language and cooldown spacing

### Moon Block / Confirmation Extraction
- Not found as a complete legacy flow
- Recommended: implement as separate calm confirmation phase in Taoist365, after primary reveal readiness gate

## Homepage Reusable Ideas

## Reusable as Inspiration (Not direct reuse)
- **Sectional narrative sequencing** (entry -> guidance -> ritual -> optional continuation)
- **Module composition architecture** for controlled experimentability
- **Ritual path discoverability** (clear paths without chat framing)
- **Visual media support capability** (banners/images) under strict atmosphere constraints

## Must Not Carry Forward
- Carousel-led hero urgency and multi-CTA pressure
- Product-grid dominance and commerce-first rhythm
- AI guide CTA prominence in global nav
- Campaign-style testimonials/newsletter conversion blocks
- Mystical/luxury spectacle styling cues

---

## Atmosphere Compatibility Findings
- Legacy has useful structural and data scaffolding, but atmosphere climate is mostly incompatible with current Taoist365.
- Strongest compatibility is in interaction sequencing logic, not visuals or copy tone.
- Recommended policy: **extract mechanics, discard mood**.

---

## Migration Guardrail (Recommended)
When consuming any Manus legacy asset, apply this gate:
1. Keep only interaction/state logic and data shape
2. Rebuild visual/tone via Taoist365 systems:
   - ritual timing
   - emotional density
   - calm hierarchy
   - live motion rules
   - ritual language system
3. Reject any artifact that introduces urgency, spectacle, chat framing, or marketplace pressure
