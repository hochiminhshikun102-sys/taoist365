# Taoist365 Design System v0

## Visual Direction
- Keywords: quiet, warm, premium, minimal, grounded.
- Avoid mystical overload, dark gold pressure, and fear-driven tone.

## Color Strategy
- 80 percent neutral warm base.
- 15 percent wood and soft gold accents.
- 5 percent cinnabar highlights for ritual moments.

## Typography
- Display: refined serif for headings.
- Body: clean sans-serif for readability.
- Spacious line-height and restrained font weights.

## UI Behavior
- Soft radius, light borders, subtle shadows.
- Slow and stable transitions (150-300ms, ease-out).
- CTA language should invite reflection, not urgency.

## Accessibility
- Ensure AA contrast on text and actions.
- Keyboard focus visible for all controls.
- Semantic HTML first for SEO and assistive tech.
