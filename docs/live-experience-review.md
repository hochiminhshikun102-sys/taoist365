# Live Experience Review

## Core Questions
- Does the user naturally slow down after entering?
- Is there enough room to pause before and after actions?
- Is reveal pacing gentle instead of sudden?
- Do CTAs interrupt emotional state?
- Does any section feel like a tool dashboard?
- Is there residual chat-app framing?
- Does the page increase agitation?
- Is quiet spatial feeling preserved?

## Surface Review Checklist
- [ ] Arrival is calm and non-urgent
- [ ] Interaction gaps are present between actions
- [ ] Reflection zone exists after reveal
- [ ] Continuation is optional and boundary-aware
- [ ] Visual silence is visible in each section
- [ ] No conversion-first pressure behavior

## Motion Review Checklist
- [ ] No bounce or flashy motion
- [ ] No reactive motion overload
- [ ] Stillness zones remain still
- [ ] Hover and focus feedback stay minimal

## Tone Review Checklist
- [ ] Language invites, not commands
- [ ] Output remains concise and calm
- [ ] Session close encourages pause, not endless continuation
