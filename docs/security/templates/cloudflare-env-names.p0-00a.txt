# Cloudflare / local env names (P0-00A)

Values stay in Dashboard / Cloudflare encrypted store. This file is names and isolation only.

## Preview (Cloudflare Pages → Settings → Environment variables → Preview)

```text
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_URL=
SUPABASE_ISSUER=
SUPABASE_JWKS_URL=
SUPABASE_SECRET_KEY=
DOHARA_RUNTIME_ENV=preview
```

`SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_URL` should both point at the **Preview** project host.

## Production (do not fill in P0-00A)

```text
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_URL=
SUPABASE_ISSUER=
SUPABASE_JWKS_URL=
SUPABASE_SECRET_KEY=
```

Leave blank until a later production-auth authorization. Never copy Preview values here.

## Local developer file (gitignored `.env*`)

Developers may create a local `.env.local` with Preview publishable URL/key only. Secret Key is optional locally and must never be committed. `.gitignore` already ignores `.env*`.
