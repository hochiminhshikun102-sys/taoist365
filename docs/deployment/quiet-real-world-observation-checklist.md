# Quiet Real-world Observation Checklist

Use after the site is reachable from Cloudflare Pages or the real domain.

This is not a launch checklist. Do not use it to create work when nothing is wrong.

## Static Access

- [ ] Cloudflare Pages serves the static export without missing routes.
- [ ] `/_headers` is present in the deployed output.
- [ ] Preview URLs stay `noindex`.
- [ ] `https://www.taoist365.com/llms.txt` opens.
- [ ] `https://www.taoist365.com/ai-readable.json` opens and remains valid JSON.
- [ ] `https://taoist365.com/*` redirects to `https://www.taoist365.com/*`.
- [ ] `/objects`, `/desk`, `/inquiry`, and `/rituals/draw-a-lot` open from a cold browser.
- [ ] `/admin` is not public without Cloudflare Access or equivalent protection.

## Multi-device Quiet Observation

Check fatigue, not polish.

- [ ] iPhone, normal brightness.
- [ ] iPhone, low brightness.
- [ ] Android, normal brightness.
- [ ] Android, low brightness.
- [ ] iPad or tablet.
- [ ] Small laptop.
- [ ] Desktop ultrawide.
- [ ] Late-night room, low brightness.

For each device, note only:

- what felt ordinary;
- what felt tiring;
- what broke;
- whether it should be left alone.

## Long-open Routine

No automation. No monitoring system.

- [ ] Leave homepage open for a day.
- [ ] Leave homepage open overnight.
- [ ] Return after several days.
- [ ] Keep taoist365 open beside unrelated tabs.
- [ ] Use back/forward navigation after a long pause.
- [ ] Reopen from browser history.
- [ ] Reopen from typed URL or bookmark.

Watch whether the page becomes more tiring over time.

## Homepage

- [ ] Does it feel peripheral enough?
- [ ] Does it welcome too much?
- [ ] Does it guide too much?
- [ ] Does it explain itself?
- [ ] Does it feel like a designed experience instead of a site?
- [ ] Does any section ask for attention after the first minute?

If no drift is clear, do nothing.

## Objects

- [ ] Objects still read as things.
- [ ] The page does not feel like a shop wall.
- [ ] Object names remain stable.
- [ ] Mail still feels like correspondence.
- [ ] No scarcity or exposure pressure appears.

If commerce pressure appears, record it before repairing.

## Mail

- [ ] Mail does not feel like newsletter capture.
- [ ] Mail does not feel like support chat.
- [ ] Mail does not promise speed.
- [ ] Mail still feels like a human route.

If it starts to feel operational, record the drift.

## Draw a Lot

- [ ] Touch rhythm stays low-pressure.
- [ ] Waiting does not feel like app state.
- [ ] Result does not feel like a verdict.
- [ ] Objects feel table-like, not staged.
- [ ] Nothing feels optimized for repeat use.

## Browser Air And Wind

- [ ] Wind remains peripheral.
- [ ] Motion does not become recognizable.
- [ ] Low brightness does not make haze feel heavy.
- [ ] Long-open tab does not become visually tiring.
- [ ] Mobile scroll remains breathable.

## AI-readable

- [ ] `llms.txt` describes stable facts.
- [ ] `ai-readable.json` describes stable facts.
- [ ] No SEO or GEO bait appears.
- [ ] Object anchors remain stable.
- [ ] Commerce remains mail-only.

## No-action Result

If nothing is broken and no drift is named:

- [ ] Do not redesign.
- [ ] Do not tune.
- [ ] Do not add tracking.
- [ ] Do not create a new pass.
- [ ] Leave the site alone.
